# Configuration

All configuration is via `.env` (copied from `.env.example`; generated by `install.sh`). Config files
under `tacacs/config/conf.d/` use `${VAR}` placeholders that the tacacs entrypoint injects at first
deploy. **Change live config through the web UI / agent (staged commit), not by hand-editing volume
files.**

## Environment variables

### General
| Var | Default | Notes |
|-----|---------|-------|
| `TZ` | `UTC` | Container timezone. |

### TACACS+
| Var | Default | Notes |
|-----|---------|-------|
| `TACACS_KEY` | (generated) | Shared secret devices use to talk to the server. |
| `TACACS_LISTEN_PORT` | `49` | Host port for TACACS+. |
| `TACACS_TLS_PORT` | `300` | Host port for TACACS+ over TLS. |
| `ENABLE_TLS` | `false` | Requires certs at `/etc/tac_plus-ng/tls/` (restart-group change). |
| `LOCAL_ADMIN_PW_HASH` | (generated) | SHA-512 crypt for the `network_admin` seed user. |
| `LOCAL_READONLY_PW_HASH` | (generated) | SHA-512 crypt for the `network_readonly` seed user. |

Generate a hash manually: `openssl passwd -6 'yourpassword'`.

### Agent
| Var | Default | Notes |
|-----|---------|-------|
| `AGENT_LISTEN_PORT` | `8081` | REST API port. |
| `AGENT_JWKS_URL` | (empty) | Supabase JWKS URL (ES256 token verification). Empty = lab no-auth. |
| `AGENT_JWT_SECRET` | (empty) | HS256 shared secret alternative to JWKS. |
| `AGENT_BACKUP_RETAIN` | `5` | Config backup snapshots kept. |
| `AGENT_NETBOX_URL` / `_HOST` / `_TOKEN` / `_INSECURE` | (empty) | NetBox DNS source-of-truth scans (optional). |

Set **either** `AGENT_JWKS_URL` **or** `AGENT_JWT_SECRET` in production so the agent enforces auth and
per-route scopes; with both empty it runs open (lab only).

### DNS
| Var | Default | Notes |
|-----|---------|-------|
| `DNS_LISTEN_ADDR` | `0.0.0.0` | Bind address for the DNS port mapping. |
| `DNS_SERVER_IP_01` | (empty) | Upstream/reverse-lookup resolver used by tac_plus-ng (optional). |

### Frontend
Build-time (baked into the bundle + `/connect-info.json`): `VITE_AGENT_URL` (`/agent`),
`VITE_SUPABASE_URL` (`/supabase`), `VITE_SUPABASE_ANON_KEY` (public). Runtime proxy upstreams:
`AGENT_UPSTREAM`, `SUPABASE_UPSTREAM`, `KEYCLOAK_UPSTREAM`.

### LDAP / Active Directory (MAVIS backend, optional)
Set `ENABLE_LDAP=true` and the `LDAP_*` vars. Key points (learned the hard way):
- **Enabling/changing LDAP is a restart-group change** - `tac_plus-ng` only spawns the MAVIS helper at
  daemon start; a SIGHUP reload will not start it.
- The image needs `libio-socket-ssl-perl` (`IO::Socket::SSL`) or the MAVIS LDAP helper fails to run
  (this is baked into `tacacs/Dockerfile`).
- **OpenLDAP** has no `memberOf` by default: set `LDAP_SERVER_TYPE=generic` and leave `LDAP_TACMEMBER`
  and the group filter blank so the reverse `groupOfNames`/`member` search is used.
- **Active Directory**: `LDAP_SERVER_TYPE=microsoft`, `LDAP_TACMEMBER=memberOf`,
  `LDAP_FILTER=(&(objectClass=user)(sAMAccountName=%s))`.
- Group membership must map to a TACACS group defined in `06-groups.cfg`.

### Maintenance
`ENABLE_LOGROTATE` (weekly process-log rotation) and `ENABLE_MONTHLY_ARCHIVE` (monthly AAA log
archiving; set false if shipping to external syslog).

## Config files (`tacacs/config/conf.d/`)
`01-logging` · `02-dns` · `03-mavis` (LDAP) · `04-devices` · `05-local-users` · `06-groups` ·
`07-profiles` · `08-ruleset` · `09-tls`. These carry the project banner comments and `${VAR}`
placeholders; the agent regenerates them on commit. The DNS zones live in `dns/zones/` (sample zones
included; replace with yours or manage via the DNS UI).
